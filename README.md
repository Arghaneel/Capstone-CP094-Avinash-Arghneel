# CopyCheck - Text Similarity and Plagiarism Detection Engine

A menu-driven Java 17 console application that compares two or more text submissions and reports how similar each pair is: word-frequency similarity, sentences that appear in both texts, and a verdict per pair.

## Quick start

Requires JDK 17 or newer.

```bash
./run.sh      # build and start the app (Windows: run.bat)
./test.sh     # build and run all tests (Windows: test.bat)
```

Full documentation is added in issue CC-12.
